# ESP32 + HLK-LD2450: локальная карта целей

Прошивка под классическую ESP32 DevKit V1 (ESP32-D0WD-V3, 4 МБ flash). ESP32 создаёт собственную Wi-Fi-точку, поэтому роутер и интернет не нужны.

## Подключение

Подключайте при отключённом USB-питании. Ориентируйтесь на надписи у контактов LD2450, а не на цвет проводов.

| HLK-LD2450 | ESP32 DevKit V1 | Назначение |
|---|---|---|
| `5V` | `VIN` или `5V` | питание радара от USB платы |
| `GND` | `GND` | общая земля |
| `TX` | `GPIO16` (`RX2`) | данные радара в ESP32 |
| `RX` | `GPIO17` (`TX2`) | команды ESP32 в радар |

`TX` и `RX` подключаются крест-накрест. Не питайте LD2450 от вывода `3V3`: для устойчивой работы используйте `5V`. На первом запуске ESP32 и радар можно питать одним качественным USB-C кабелем через ESP32.

Не подключайте одновременно два независимых источника к линии `5V/VIN`. Если позже понадобится отдельный БП для радара, обязательно объедините земли и сначала проверьте схему питания.

## Запуск интерфейса

1. Подайте питание и дождитесь запуска ESP32.
2. На компьютере подключитесь к Wi-Fi `LD2450-Radar`.
3. Пароль: `radar2450`.
4. Откройте `http://192.168.4.1` (также может работать `http://ld2450.local`).

Страница показывает до трёх целей, координаты X/Y, скорость, расстояние, траектории и состояние UART. Если написано «Нет данных UART», проверьте питание, общую землю, перекрёстное подключение TX/RX и заводскую скорость LD2450 `256000` бод.

## Просмотр по USB на Windows

Скачайте `LD2450-Monitor.exe` из раздела Releases либо соберите его из исходников `pc_app/ld2450_monitor_v2.py`. Приложение автоматически выбирает CP210x и подключается к ESP32; Wi-Fi для этого режима не требуется. Координаты поступают по USB со скоростью `115200` бод, одновременно с веб-интерфейсом прошивки.

Новая версия показывает квадратный план помещения, три прямоугольные зоны («Вход», «Рабочая зона», «Диван»), текущее количество людей, время присутствия по зонам и таймлайн активности/заполненности за 1, 6 или 24 часа. Запись включена по умолчанию; её можно приостановить кнопкой в нижней строке.

Кнопка «Редактировать зоны» включает режим разметки: прямоугольник можно перетащить целиком или изменить его размер угловыми маркерами. Шестерёнка открывает калибровку помещения — ширину и глубину комнаты, положение и поворот радара, отражение оси X и степень сглаживания. Для начала достаточно измерить комнату рулеткой; сложная многоточечная калибровка не требуется.

Для устойчивого отображения координаты сглаживаются экспоненциальным фильтром, а на границах зон действует гистерезис 15 см. Благодаря этому маркеры и счётчики не должны переключаться туда-сюда от небольшого шума радара.

История хранится локально 30 дней в `%LOCALAPPDATA%\LD2450Monitor\history_rect.db`, а калибровка и зоны — в `%LOCALAPPDATA%\LD2450Monitor\settings.json`. При первом запуске прежние значения активности и заполненности переносятся из `history.db`, но старые угловые зоны намеренно сбрасываются. Данные не отправляются в интернет и сохраняются после перезапуска приложения. Проценты заполненности считаются только за фактическое время записи.

Машиночитаемые строки начинаются с `LD2450_DATA` и имеют формат:

```text
LD2450_DATA,uptime_ms,frame,valid,x_mm,y_mm,speed_cm_s,resolution_mm,...
```

После счётчика кадра идут пять полей для каждой из трёх целей.

## Для чего внешняя антенна LD2450

Это Bluetooth-антенна для связи радара с мобильным приложением HLK Radar Tool: настройки, обновление и диагностика. Радиолокационные 24-ГГц антенны уже выполнены на самой плате LD2450.

Для работы UART и этого веб-интерфейса внешняя Bluetooth-антенна не обязательна. Без неё сам радар продолжает измерять цели, но Bluetooth-связь становится слабой и нестабильной; на расстоянии антенну лучше подключить.

## Повторная сборка и прошивка

Проект предназначен для PlatformIO:

```powershell
pio run
pio run --target upload
pio device monitor
```

PlatformIO автоматически выбирает доступный последовательный порт. Если подключено несколько плат, порт можно указать разово: `pio run --target upload --upload-port COM9`.

## Сборка Windows-приложения

```powershell
cd pc_app
python -m pip install -r requirements.txt
python -m unittest -v test_ld2450_monitor_v2.py
pyinstaller --noconfirm --clean LD2450-Monitor-v2.spec
```

Готовый файл появится в `pc_app/dist_v2` либо в каталоге `dist`, если путь сборки не переопределён.
